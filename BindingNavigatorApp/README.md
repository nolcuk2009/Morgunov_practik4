# BindingNavigatorApp
Лабораторная: Entity Framework + источники данных + BindingNavigator (просмотр, добавление, изменение, удаление пользователей).

1. В SSMS выполнить `SQL/DB_Users.sql` (сервер `.\SQLEXPRESS`).
2. Открыть `BindingNavigatorApp.sln` в Visual Studio и нажать F5.
3. Кнопки навигатора: перемещение по записям, «Добавить», «Удалить», «Сохранить».
